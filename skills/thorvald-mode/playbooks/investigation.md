### Investigation Playbook

1. **Drive `research`**: Trace execution paths, `git log` / `git blame`, issue tracker context (`acli`, `gh`), and runtime logs against primary sources.
2. **Prove Claims**: Back every architectural or operational claim with clickable `file://` symbol links or command outputs.
3. **Zero Git Pollution**: Deliver findings concisely in chat or in `<appDataDir>/brain/<conversation-id>/`—never leave untracked markdown notes in the Git working tree.
